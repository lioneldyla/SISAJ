# Prochaine étape après livraison Render v0.3

1. Le propriétaire prépare le dépôt privé et lance le Blueprint de démonstration selon `deploy/RENDER.md`.
2. Vérifier sur le domaine HTTPS réel : initialisation, rôles, import synthétique, rapports, redémarrage et reprise ; consigner le commit, la date et les résultats.
3. Faire approuver le dictionnaire métier : juridiction/clé, personnes et effectifs, qualifications, décisions mixtes, mesures, devises, dates de rattachement et indicateurs officiels.
4. Construire ensuite le modèle relationnel et ses migrations à partir de ces arbitrages, avec jeux synthétiques de référence signés.

Critère de clôture de la démonstration : déploiement réellement observé et parcours essentiels vérifiés, sans donnée réelle. Ce critère n’est pas encore satisfait sur Render dans cette livraison.
